# Implement Feature
1. Clarify expected behavior, acceptance criteria, boundaries and non-goals.
2. Inspect existing interfaces, patterns, dependencies, tests and security constraints.
3. Propose a minimal implementation and flag risky migrations or external actions.
4. Implement only the authorized scope; preserve compatibility and handle failure paths.
5. Add and run appropriate success, failure and boundary tests.
6. Review the diff for unintended changes, reliability, security and accessibility concerns.
7. Report criteria met or unmet, files changed, actual verification results and remaining risks.
