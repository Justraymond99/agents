# Investigate Bug
1. Identify expected versus actual behavior, environment and impact.
2. Inspect relevant code, tests, logs and changes; distinguish observations from hypotheses.
3. Reproduce safely if feasible; otherwise explain why reproduction is unavailable.
4. Identify the failure mechanism with supporting evidence.
5. Propose the smallest safe fix and request approval for high-impact actions.
6. If authorized, implement without weakening safeguards.
7. Rerun reproduction and relevant regression tests; report commands and actual results.
8. Summarize cause/confidence, changes, residual risks and next steps.
